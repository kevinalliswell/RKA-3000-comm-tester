# RKA-3000 通信测试工具 v0.2.0-rc1

Windows 10/11 x64 私有预发布。包含管理员登录、三设备扫描与单次写入、真机只读采集和模拟协议写入稳定性测试、诊断包导出。

## 安装

- 安装包：运行 `RKA-Comm-Tester-Setup-0.2.0-rc1-win-x64.exe`。
- 便携版：解压 ZIP 后运行 `RKACommTester\RKACommTester.exe`。
- 首次运行创建本地管理员账号和密码。无需安装 Python。
- 资产未签名，Windows 可能显示“未知发布者”；请核对同一发布页的 `SHA256SUMS.txt`。

## 测试边界

真机写入只允许人工单次触发；Azbil SP-0 属于 EEPROM，不用于循环压测。模拟写入不能证明真机的写入寿命或吞吐。现场真机联调和连续 8 小时验收须由现场测试结果确认。
