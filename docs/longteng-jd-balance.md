# 龙腾 JD 系列电子天平：串口协议与现场记录

本文整理自沈阳龙腾电子《JD 系列电子天平 AⅡ版使用说明书》（以下称说明书）、2021 年的三份串口调试记录和 2026-11-11 在 RKA-3000 天平上的实测，供本工具和以后接入同型号天平的项目复用。说明书原件和原始记录不随仓库分发；本文给出的章节号均对应说明书页码。

工具中的实现见 `src/rka_comm_tester/_vendor/balance_serial/protocols/longteng.py` 和 `scanner.py` 的天平探测器；判定规则汇总在 [通讯协议与诊断边界](protocols.md)。

## 型号与分辨率

说明书 §1.3 列出三档分辨率，接口均为标配 RS-232C（USB-B 为选配改制，§6）。

| 系列 | 型号 | 量程 | 最小读数 | 稳定时间 |
| --- | --- | --- | --- | --- |
| JD-2 | JD500-2 ～ JD5000-2 | 500–5000 g | 0.01 g | 约 3 s |
| JD-3 | JD100-3 ～ JD1000-3 | 100–1000 g | 0.001 g | 约 3 s |
| JD-4 | JD100-4 ～ JD210-4 | 100–210 g | 0.0001 g | < 5 s |

调试记录中的读数为 3 位小数，对应 JD-3 系列。

## 串口参数

| 项目 | 取值 | 依据 |
| --- | --- | --- |
| 波特率 | 1200 / **2400** / 4800 / 9600 bps，出厂 2400 | §4.1 参数 `C4`（`C4-0`=2400，`C4-1`=1200，`C4-2`=4800，`C4-3`=9600） |
| 数据位 / 校验 / 停止位 | 8 / 无 / 1 | §6.1 |
| 编码 | ASCII，行尾 `CR LF` | §6.1，调试记录十六进制已核对 |
| 接线 | 天平 9 针与电脑 9 孔直连：2–2、3–3、5–5 | §6.3（直连线，不是交叉线） |

参数设置方法（§4.1）：连续按两次【打印】显示 `Cx—y`；【打印】切换参数号 x，【模式】切换功能号 y；按【去皮】保存并关闭显示，再按【开/关】生效。

## 输出方式

由参数 `C5` 决定（§4.1、§6.2）：

| 设定 | 方式 | 何时输出 |
| --- | --- | --- |
| `C5-0` | 回零稳定输出 | 先显示稳定零值，放上样品后显示稳定时输出一组 |
| `C5-1` | 稳定输出 | 每当显示稳定时输出一组 |
| **`C5-2`（出厂）** | 打印键 / 命令控制输出 | 只有按【打印】键或收到 `P` 命令时输出一组 |
| `C5-3` | 连续输出 | 约每 0.3 s 输出一组（说明书）；现场实测约 0.2 s |

出厂设定下天平不会主动发送任何数据，只监听串口的上位机收不到一个字节。本工具因此在选择龙腾协议时主动发送 `P`。

## 数据帧

说明书 §6.1 的格式为 `FXXXX.XXXXKKK<CR><LF>`：

| 字段 | 含义 |
| --- | --- |
| `F` | 符号位，`+` 或 `-` |
| `X…` | 重量数字和小数点，位数随型号分辨率变化 |
| `KKK` | 3 个字符的称量单位，右对齐，不足 3 位时左侧补空格 |
| `CR LF` | `0D 0A` |

**稳定判定**：输出不稳定的重量时，单位位 `KKK` 三位全是空格；稳定时才带单位。

| 帧 | 说明 |
| --- | --- |
| `+0010.0000 g` | 说明书示例，+10.0000 g，稳定 |
| `+00100.001  g` | 现场记录，+100.001 g，稳定 |
| `-00100.002  g` | 现场记录，去皮后取下砝码，负值 |
| `+00100.001   ` | 单位位为空格：不稳定（按说明书构造） |

现场记录的十六进制（2021-07-01）逐字节对应一帧共 15 字节：

```text
2B 30 30 30 30 39 2E 30 34 32 20 20 67 0D 0A
 +  0  0  0  0  9  .  0  4  2 ␠  ␠  g CR LF   → +9.042 g，稳定
```

天平支持多种称量单位和计件、百分比称量（§1.2、§3），这时 `KKK` 不是 `g`。本工具只把单位为 `g` 的稳定帧当作克重。

### 带状态头的帧（RKA-3000 天平实测）

2026-11-11 在 RKA-3000 配套天平上抓到的帧与说明书格式不同：前面多了状态头 `ST,`，行尾是 `CR LF LF`，每帧 18 字节。

```text
53 54 2C 2D 30 30 34 35 2E 35 37 38 20 20 67 0D 0A 0A
 S  T  ,  -  0  0  4  5  .  5  7  8 ␠  ␠  g CR LF LF   → -45.578 g，稳定
```

| 部分 | 含义 |
| --- | --- |
| `ST,` | 状态头，`ST` 表示稳定 |
| `-0045.578` | 符号、4 位整数、3 位小数 |
| `␠␠g` | 3 位单位字段，与说明书一致 |
| `CR LF LF` | 多一个换行，按行读取时每帧之后会多出一个空行 |

本工具的处理：

- `ST,` 帧为稳定读数，单位缺省时按克处理（兼容上游早期格式 `ST,12.345`）。
- `US,` 帧按这类帧头的通行约定当作不稳定读数，**尚未在本天平上实测**。
- 其他帧头记为未知帧。
- 空行算作收到了数据，不会再触发打印命令 `P`。

同一型号出现两种格式，原因可能是固件版本或输出设置不同；说明书没有提到 `ST,` 头。

## 命令

上位机发送 1 个字母加 `CR LF`（§4.2）。天平收到有效命令后**立即原样回发该字母**作为应答；命令无效时回发 `Err`。

| 命令 | 字节 | 等同按键 | 本工具 |
| --- | --- | --- | --- |
| `O` | `4F 0D 0A` | 【开/关】 | **从不发送**（会关闭显示） |
| `T` | `54 0D 0A` | 【去皮】 | 仅在「去皮测试」中、操作员确认后发送一次 |
| `C` | `43 0D 0A` | 【校准】 | **从不发送** |
| `M` | `4D 0D 0A` | 【模式】 | **从不发送**（会切换称量模式） |
| `P` | `50 0D 0A` | 【打印】 | 扫描和去皮测试中用于请求读数 |

`P` 只让天平输出一组当前重量，不改变零点、模式或任何参数，因此不突破扫描的只读边界。GS-CPA 协议的 `O1`/`O0` 不能发给龙腾天平：`O` 在龙腾上是开关命令。

## 现场调试记录

三份记录由串口调试助手保存，串口参数未记录在案。时间均为 2021 年，相对时间以毫秒计。

### 2021-06-23 第一段：连续输出

天平处于连续输出（相当于 `C5-3`），秤盘上为 100 g 砝码。15:21:30 至 15:22:23 每约 200 ms 收到一帧 `+00100.001  g`，读数稳定不变。

### 2021-06-23 第二段：去皮与打印命令

| 时间 | 方向 | 内容 | 说明 |
| --- | --- | --- | --- |
| 15:23:59–15:24:01 | 收 | `+00100.001  g` | 连续输出，约 200 ms 一帧 |
| 15:24:01.295 | 发 | `54 0D 0A`（`T`） | 去皮 |
| +70 ms | 收 | `T` | 命令回显，与上一帧同批到达 |
| +253 ms 起 | 收 | `+00000.000  g` | 去皮后读数为零，持续到 15:24:37 |
| 15:25:21 起 | 收 | `-00100.002  g` | 取下砝码，读数为负 |
| 15:25:24.760 | 发 | `T` | 再次去皮 |
| +69 ms | 收 | `T` | 回显 |
| +184 ms 起 | 收 | `+00000.000  g` | 回零；15:25:27 后连续输出停止 |
| 15:26:30 起 | 发 | `50 0D 0A`（`P`），每 0.5 s 或 1 s | 天平已不再主动输出 |
| 每次 +106–113 ms | 收 | `P` | 回显 |
| 回显后 9–111 ms | 收 | `+00100.000  g` | 每个 `P` 恰好返回一组读数 |

结论：

- 去皮在约 70 ms 内回显 `T`，约 0.2 s 内读数回零。
- 打印命令在约 0.1 s 内回显 `P`，约 0.2 s 内返回一组读数，每次请求只返回一组。
- 连续输出停止后用 `P` 仍能读数，与说明书 `C5-2` 的行为一致。

### 2021-07-01：十六进制核对

16:45:03 至 16:45:15 以十六进制显示接收，每约 200 ms 一帧 `+00009.042  g`，帧格式和行尾 `0D 0A` 如上节所示。第一行只收到 `67 0D 0A`，是从一帧中途开始抓取所致，读取方应丢弃不完整的首行。16:45:37 之后切回 ASCII 显示，内容相同。

### 2026-11-11：RKA-3000 天平，连续稳定输出

用串口调试助手在 RKA-3000 配套天平上测试，天平设为连续稳定输出，2400 bps。秤盘处于去皮后取下物品的状态，读数稳定在 -45.578 g。

- 14:12:06.854 至 14:12:12.263 以十六进制接收：每帧 `53 54 2C 2D 30 30 34 35 2E 35 37 38 20 20 67 0D 0A 0A`，即 `ST,-0045.578  g` 加 `CR LF LF`。
- 14:12:12.453 至 14:12:18.066 切回 ASCII 显示，内容相同；多出的 `LF` 在调试助手里显示为空行。
- 帧间隔 186–219 ms，约 200 ms，与 2021 年记录一致。
- 这一段没有发送命令；命令的实测见下一节。

### 2026-11-11 第二次：连续输出下的 `P` 与 `T`

同一台天平，15:38 继续保持连续稳定输出，用调试助手发送命令（接收按 ASCII 显示）。

| 时间 | 发送 | 收到 | 说明 |
| --- | --- | --- | --- |
| 15:38:19.168–24.390 | `50 0D 0A`（`P`）共 7 次 | 5 次在 109–234 ms 后看到单独一行 `P`，在相邻帧之前或之后；另 2 次（20.743、23.734）只多出一个空行，没有看到 `P` | 帧节奏不变，也不多出一帧；连续输出下 `P` 至多产生一行回显，回显不一定能完整收到 |
| 15:38:40.860 | — | `566  g` | 接收从一帧中途开始，残缺行应丢弃 |
| 15:38:42.297 | `54 0D 0A`（`T`） | 约 190 ms 后 `TT,-0045.565  g` | 回显 `T` 与正在发送的帧相撞，帧头 `S` 丢失，这一帧仍是去皮前的重量 |
| 15:38:42.483–42.905 | — | 约 0.4 s 无输出 | 天平执行去皮 |
| 15:38:42.905 起 | — | `ST,+0000.000  g` | 去皮完成，约 0.6 s 后回零 |
| 15:38:44.608、45.666、46.684 | `T` 共 3 次 | 约 110 ms 后单独一行 `T` | 读数已为零时的回显，零点保持不变 |

结论：

- 回显和数据帧共用一条线路，可能出现在帧前、帧后，可能和帧撞在一起变成残缺行，也可能看不到。读取方应把残缺行当作未知帧丢弃，而不能依赖回显来确认去皮；本工具以去皮后读到的稳定零点为准。
- 去皮从发命令到回零约 0.6 s，远小于工具默认的 5 s 去皮等待。
- 帧头 `US,`（不稳定）在本次记录中没有出现，仍未实测。

## 排查顺序

1. 串口号正确且未被其他程序占用（Windows 上报「拒绝访问」即被占用）。
2. 波特率与天平 `C4` 一致，8N1；不确定时先试出厂值 2400。
3. 串口线为 2–2、3–3、5–5 直连线；USB 转 RS-232 适配器驱动已安装。
4. 协议选择「龙腾」，不勾选 O1。
5. 仍收不到数据时，看通信日志里的 `发送: 50 0d 0a` 和 `接收:` 行：有发送无接收是线路或波特率问题；有接收但解析不出是波特率或协议问题。
