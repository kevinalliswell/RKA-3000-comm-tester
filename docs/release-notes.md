RKA-3000 通信测试工具 `0.1.1` 正式版，使用 Tauri 2 + Svelte 5/TypeScript 桌面窗口，Python 负责业务、数据与串口通信。

相较 `0.1.0`：

- 新增独立的电子天平「去皮测试」，适用于 GS-CPA 和龙腾协议。操作员确认后仅发送一次去皮命令，等待指定容差内的稳定零点；与扫描共用任务互斥与取消清理，不参与自动复查。
- 去皮确认读取受总截止时间约束，持续无换行数据不能延长等待；到达或超过截止时间的零点帧不会误判成功。未知响应归为 `degraded` 并保留诊断，无响应才为 `offline`。
- 后端启动失败时保留桌面窗口并显示原因，诊断写入 `desktop.log`；窗口无法创建时显示 Windows 系统错误框。
- 桌面进程异常退出后，Python 后端通过 stdin EOF 自动收尾退出，避免残留进程。发布包只运行随包后端；Python 解释器回退仅限开发构建。
- 修复通过 `python -m` 启动时 API 日志不落盘的问题，同步协议、架构和分层文档。

本版提供 Windows x64 安装器、便携包和 SHA-256 校验文件，内置 Python，无需安装开发工具。标签触发的 CI 会重新执行 58 项 Python 测试、前端类型检查、冻结打包、窗口/后端退出检查以及安装/卸载验收，全部通过后才创建 Release。

下载 `*_setup.exe` 安装，或完整解压 `*_portable.zip` 后运行主程序。支持 Windows 10/11 x64；安装器会联网补齐 WebView2，便携版需已安装 WebView2。当前未配置 Windows 代码签名，系统可能显示未知发布者。

配置与日志位于 `%USERPROFILE%\.rka-comm-tester\`，升级/卸载保留。扫描保持只读，不提供设定值或任意寄存器写入。天平去皮会改变零点，必须由操作员主动确认；命令发出后取消只能停止等待，不能撤销已生效的去皮。GS-CPA 的 O1 仅在主动启用连续输出时发送，结束时发送 O0。真机去皮及现场通信仍需连接实际设备验收，离线测试不能替代现场验证。
