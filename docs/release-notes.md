Tauri 2 + Svelte 5/TypeScript 桌面首个候选版，Python 负责业务、数据与串口通信。此为预发布，尚需现场设备验收。

- 分离表示、桌面、API、应用、领域与基础设施层；开发和冻结后端复用相同业务代码。
- 修正协议校验、扫描状态、取消收尾与天平连续输出清理，统一界面状态配色。
- 提供 Windows x64 安装器、便携包和 SHA-256 校验文件，内置 Python，无需安装开发工具。
- CI 自动执行测试、类型检查、冻结打包、窗口/后端退出检查以及安装/卸载验收；标签触发发布。

下载 `*_setup.exe` 安装，或完整解压 `*_portable.zip` 后运行主程序。支持 Windows 10/11 x64；安装器会联网补齐 WebView2，便携版需已安装 WebView2。当前未配置 Windows 代码签名。

配置与日志位于 `%USERPROFILE%\.rka-comm-tester\`，升级/卸载保留。工具不提供设定值、去皮或任意寄存器写入；GS-CPA 的 O1 仅在主动启用连续输出时发送，结束时发送 O0。离线测试不能代替真机验收。
